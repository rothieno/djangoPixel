Shipping & returns.

Here’s how delivery and returns are represented in this demo shop. These details are examples—not a live fulfillment or returns service.

01 / SHIPPING

Shipping shown at checkout

The demo cart applies a flat ${{ standard_shipping|floatformat:2 }} shipping charge when the subtotal is under ${{ free_shipping_threshold|floatformat:0 }}. Orders at or above that amount show free shipping.

No carrier, delivery date, or real shipment is arranged. Delivery rates and timing would need to be configured for a live store.

02 / RETURNS

Returns aren’t enabled yet

This project does not record orders, so it cannot accept or process a return or exchange. No return window or eligibility promise is implied by this demo page.

Before launching a real shop, add a clear return policy and a monitored customer-support contact.
